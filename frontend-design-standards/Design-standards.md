# 前端设计标准 · 路由总纲

本项目采用 **“双设计系统混搭”** 策略，根据页面类型自动切换设计源。

---

## 🎵 应用端（面向用户）
**适用场景**：首页、播放器、歌单详情、歌手页、搜索页等所有用户可见页面。

**设计源**：`design-spotify.md`

**核心视觉基因**：
- 暗色画布（#121212 基底）
- 高饱和强调色（绿/紫/粉/白）
- 内容优先，大图驱动
- 沉浸式播放器体验

**使用指令**：
> “按照 `design-spotify.md` 的风格，生成[页面名称]。”

---

## 🛠️ 管理端（后台操作）
**适用场景**：数据仪表盘、歌曲管理、歌单管理、用户管理、系统设置等后台页面。

**设计源**：`design-linear.md`

**核心视觉基因**：
- 浅色/暗色双模（以浅色为主）
- 紫色系强调色（#5E6AD2）
- 信息层级清晰，表格/列表友好
- 紧凑高效，适合操作密集场景

**使用指令**：
> “按照 `design-linear.md` 的风格，生成[页面名称]。”

## 🔐 登录/注册页（独立门面协议）

**适用场景**：登录页、注册页、忘记密码页。

**设计源**：继承 `design-spotify.md` 的暗黑基因，但为了提升表单可用性，应用以下 **“登录页专用微调规则”**：

1. **背景**：纯黑渐变深色（`#000000` → `#121212`），不加复杂背景图，避免干扰输入框。
2. **表单容器**：使用**毛玻璃效果**（`backdrop-filter: blur(20px)`），背景为半透明白色（`rgba(255,255,255,0.05)`），让登录框浮在暗色背景上，增加层次感。
3. **输入框**：深色背景 + 白色文字 + 底部亮色下划线（强调色 `#D4A745`），确保在暗色背景下清晰可辨。
4. **按钮**：纯色高亮（琥珀金 `#D4A745`），悬停时增加发光光晕，点击时加入“音浪波纹”微动效（呼应音乐主题）。
5. **Logo 与标题**：顶部居中放置项目 Logo + 极简 Slogan（如“让音乐流动”），建立品牌认知。

**使用指令**：
> “按照应用端（Spotify）风格，并应用登录页微调规则，生成登录/注册页面。”



## 🔄 颜色系统桥接（统一 Token）

为了确保两个设计系统在切换时不割裂，定义以下全局 CSS 变量（在 `design-tokens.css` 中统一管理）：

```css
:root {
  /* 统一品牌色（两个系统共享） */
  --brand-primary: #1A1A2E;    
  --brand-accent: #373761;   

  /* 注意：背景色、字体、圆角等各自遵循 design-spotify.md 和 design-linear.md */
}
