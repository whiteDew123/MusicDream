# 前端设计标准 · 路由总纲（亮色版）

本项目采用 **“双设计系统混搭”** 策略，根据页面类型自动切换设计源。两端均为亮色/浅色系，确保视觉风格统一。

---

## 🎵 应用端（面向用户）
**适用场景**：首页、播放器、歌单详情、歌手页、搜索页、登录/注册页等所有用户可见页面。

**设计源**：`design-stripe.md`

**核心视觉基因**：

- 浅色基底（`#f6f9fc` 页面底色 + `#ffffff` 卡片）
- 紫色强调色（`#5e5ce6`）
- 大量留白、大标题、卡片式布局
- 干净、通透、高级感

**使用指令**：
> “按照 `design-stripe.md` 的风格，生成[页面名称]。”


## 🛠️ 管理端（后台操作）
**适用场景**：数据仪表盘、歌曲管理、歌单管理、用户管理、系统设置等后台页面。

**设计源**：`design-webflow.md`

**核心视觉基因**：
- 纯白/极浅灰基底
- 蓝色系强调色（`#4353ff`）
- 信息层级清晰，表格/列表友好
- 专业、干净、操作高效

**使用指令**：
> “按照 `design-webflow.md` 的风格，生成[页面名称]。”


## 🔐 登录/注册页（独立门面协议）

**适用场景**：登录页、注册页、忘记密码页。

**设计源**：继承 `design-stripe.md` 的亮色基因，应用以下 **“登录页专用微调规则”**：

1. **背景**：极浅蓝灰渐变（`#f0f4f8` → `#e2e8f0`），柔和通透，不抢视觉重心。
2. **表单容器**：纯白卡片（`#ffffff`），带轻微阴影（`0 4px 20px rgba(0,0,0,0.06)`），浮在浅色背景上，层次清晰。
3. **输入框**：浅灰背景（`#f1f4f9`）+ 深色文字（`#1a1a1a`）+ 聚焦时紫色边框（`#5e5ce6`），确保在亮色背景下清晰可辨。
4. **按钮**：纯色高亮（紫色 `#5e5ce6`），悬停时加深（`#4a3fcf`），点击时加入“音浪波纹”微动效（呼应音乐主题）。
5. **Logo 与标题**：顶部居中放置项目 Logo + 极简 Slogan（如“让音乐流动”），建立品牌认知。

**使用指令**：
> “按照应用端（Stripe）风格，并应用登录页微调规则，生成登录/注册页面。”


## 🔄 颜色系统桥接（统一 Token）

为了确保两个设计系统在切换时不割裂，定义以下全局 CSS 变量（在 `design-tokens.css` 中统一管理）：

```css
:root {
  /* 统一品牌色（两个系统共享） */
  --brand-primary: #5e5ce6;      /* Stripe 紫，两端统一 */
  --brand-primary-hover: #4a3fcf;
  --brand-accent: #4353ff;       /* Webflow 蓝，用于管理端强调 */

  /* 亮色系统共用基底 */
  --color-bg-page: #f6f9fc;      /* 页面底色 */
  --color-bg-card: #ffffff;      /* 卡片底色 */
  --color-text-primary: #1a1a1a; /* 主文字 */
  --color-text-secondary: #6b7280; /* 辅助文字 */

  /* 注意：各端具体组件样式遵循各自设计源文件 */
}
