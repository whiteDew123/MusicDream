## 🎮 交互体验协议 · 音乐项目专属（v2.0）

### 适用范围说明

| 设计源                        | 适用的交互协议章节                             |
| :---------------------------- | :--------------------------------------------- |
| `design-spotify.md`（应用端） | **第一、二、三章**（播放器 + 内容浏览 + 反馈） |
| `design-linear.md`（管理端）  | **第四章**（管理后台专属）                     |
| 两者共用                      | **第五章**（全局基础交互）                     |

### 第一章 · 应用端：播放器核心交互（Spotify 专属）

> 以下交互仅应用于播放器界面、歌单详情页、当前播放栏。

| 交互场景                      | 行为描述                                                     | 参数规格                                                     |
| :---------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **播放/暂停按钮**             | 点击时图标切换伴随弹性缩放动画，模拟“启动音乐”的物理感       | `transform: scale(0.85) → 1.1 → 1`，时长 350ms，缓动 `ease-out` |
| **进度条拖拽**                | 拖拽时滑块圆点放大 1.3 倍，松手后回弹；拖拽过程中显示实时时间戳浮标 | 圆点放大过渡 150ms；时间戳浮标跟随鼠标位置，带 100ms 延迟跟随 |
| **音量滑块**                  | 悬停时滑块轨道高亮（Spotify Green），拖拽时圆点放大 1.2 倍   | 轨道高亮过渡 200ms；圆点缩放 150ms                           |
| **歌曲切换（上一首/下一首）** | 点击时当前歌曲信息做“滑出”过渡，新歌曲“滑入”                 | 滑出 200ms `ease-in`，滑入 250ms `ease-out`，间隔 50ms       |
| **歌词滚动（如有）**          | 歌词随播放进度自动滚动，当前行高亮并居中                     | 自动滚动使用 `scrollIntoView` 配合 `smooth`，高亮行颜色使用 Spotlight Green |

### 第二章 · 应用端：内容浏览交互（Spotify 专属）

> 以下交互应用于首页、歌单列表、歌手页、搜索结果等浏览场景。

| 交互场景                      | 行为描述                                                     | 参数规格                                                     |
| :---------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **歌单/专辑卡片悬停**         | 卡片略微上浮，同时显示一个“播放”按钮（圆形，Spotify Green）从透明渐显 | 上浮 `translateY(-4px)`，过渡 250ms；播放按钮渐显 300ms `ease-out` |
| **列表项悬停**                | 歌曲列表项背景变亮（从 `#121212` → `#1f1f1f`），同时右侧出现“···”更多菜单按钮 | 背景过渡 150ms；更多按钮渐显 200ms                           |
| **列表项点击**                | 点击后高亮保持（表示“当前选中/正在播放”），左侧出现 Spotify Green 竖条指示器 | 竖条宽度 4px，出现动画 200ms `ease-out`                      |
| **列表加载（分页/滚动加载）** | 新条目从下往上滑入，每条间隔 50ms，形成交错入场效果          | `translateY(12px) → 0`，透明度 0 → 1，每条 300ms，间隔 50ms  |
| **搜索输入**                  | 输入时自动展开搜索建议下拉，建议项悬停时背景变亮             | 下拉展开 300ms `ease-out`；建议项悬停 150ms                  |
| **下拉刷新（移动端）**        | 下拉时顶部出现加载指示器（Spotify Green 旋转圆环），松手后刷新 | 圆环旋转动画 800ms 循环；刷新完成后 300ms 淡出               |

### 第三章 · 应用端：反馈与过渡（Spotify 专属）

> 以下交互应用于全局反馈、页面流转、等待状态。

| 交互场景                  | 行为描述                                                     | 参数规格                                                     |
| :------------------------ | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **页面切换**              | 路由跳转时使用平滑淡入淡出，避免生硬闪屏                     | `opacity: 0 → 1`，时长 250ms `ease-out`                      |
| **收藏/点赞操作**         | 点击心形图标时，图标做“弹跳”动画，同时触发微小的粒子爆裂效果（可选） | 弹跳：`scale(0.6 → 1.3 → 1)`，时长 400ms；粒子效果（若实现）持续 600ms |
| **Toast 提示**            | 操作成功/失败时，从页面底部或顶部滑入轻提示，附带进度条自动消失，并提供“撤销”按钮（如适用） | 滑入 350ms `ease-out`，停留 3 秒，滑出 300ms `ease-in`；进度条从左到右填充 3 秒 |
| **骨架屏（加载中）**      | 所有列表/卡片加载时优先显示骨架屏，骨架颜色取当前背景色与卡片背景色的中间色（例如 `#1a1a1a`） | 骨架脉冲动画：透明度 0.5 ↔ 1，循环 1.2 秒                    |
| **操作确认（删除/清空）** | 危险操作触发二次确认对话框，对话框背景带毛玻璃效果，点击“确认”前不执行 | 对话框出现 300ms `scale(0.95 → 1)` + 背景遮罩 200ms 淡入     |

### 第四章 · 管理端专属交互（Linear 风格）

> 以下交互仅应用于管理后台（数据面板、歌曲管理、歌单管理、用户管理等），遵循 Linear 的“高效、克制、工具感”设计哲学。

| 交互场景                   | 行为描述                                                     | 参数规格                                                     |
| :------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **表格行悬停**             | 行背景轻微变亮（从 `#0f1011` → `#141516`），同时行左侧出现 2px 紫色（`#5e6ad2`）竖条 | 背景过渡 150ms；紫色竖条出现 200ms `ease-out`                |
| **表格行点击选中**         | 点击行时高亮保持（紫色竖条保留），表示“当前选中项”           | 高亮状态无动画，瞬时切换（工具感优先）                       |
| **侧边栏折叠/展开**        | 侧边栏折叠时图标保留，文字淡出；展开时文字淡入               | 折叠 250ms `ease-in-out`，文字透明度过渡 200ms               |
| **数据加载（分页/筛选）**  | 表格内容切换时使用“淡入替换”效果，避免抖动                   | 旧内容淡出 150ms，新内容淡入 200ms，间隔 50ms                |
| **表单提交**               | 点击提交按钮时，按钮变为“加载中”状态（文字变为“保存中...”，禁用点击），提交完成后恢复 | 加载状态无过渡，瞬切；恢复后绿色成功提示淡入 300ms           |
| **拖拽排序（如歌单排序）** | 拖拽时卡片/行带阴影悬浮，拖拽到位后其他元素让位动画          | 悬浮阴影使用 `rgba(94,106,210,0.2) 0px 8px 24px`；让位动画 250ms `ease-out` |
| **筛选/搜索**              | 输入筛选条件后，结果列表 300ms 内更新，无入场动画（追求响应速度） | 300ms 内完成数据刷新，无额外动效                             |

### 第五章 · 全局基础交互（两端共用）

> 以下交互同时应用于应用端和管理端，保证基础体验的一致性。

| 交互场景         | 行为描述                                                     | 参数规格                                                     |
| :--------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **滚动条**       | 全局自定义滚动条：细条 + 圆角，轨道透明，滑块使用当前页面的强调色 | 宽度 6px，圆角 3px；滑块颜色：应用端用 Spotify Green，管理端用 Linear 紫 |
| **链接悬停**     | 所有文字链接悬停时加下划线或变色                             | 下划线出现 200ms，或颜色过渡 150ms                           |
| **加载 Spinner** | 仅在骨架屏不可用的极少数场景使用（如按钮内加载），使用对应品牌的强调色圆环 | 旋转动画 1s 线性循环                                         |
| **焦点指示**     | 所有可交互元素（按钮、输入框、链接）获得键盘焦点时，显示品牌色聚焦环 | 2px 聚焦环，颜色：应用端用 Spotify Green，管理端用 Linear 紫，偏移 2px |

### 📋 交互协议与设计文档的配合方式

| 设计文档            | 负责内容                                                     | 本协议负责内容                                               |
| :------------------ | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `design-spotify.md` | 颜色、字体、圆角、阴影、**静态悬停变色**                     | 播放器弹性缩放、卡片入场动画、页面过渡、骨架屏、Toast 滑入滑出 |
| `design-linear.md`  | 颜色、字体、圆角、**按钮 pressed/hover 状态**、**聚焦环**、**触摸目标尺寸** | 表格行悬停竖条、侧边栏折叠、拖拽排序、表单提交加载状态       |
