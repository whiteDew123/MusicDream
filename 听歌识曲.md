# 听歌识曲功能 —— 工程实现与算法详解

## 一、核心概念

- **音频指纹**：每首歌独一无二的声学特征摘要，是匹配的核心依据。
- **PCM（脉冲编码调制）**：最原始的数字音频，是一段连续的二进制数字流，代表声波在不同时间点的振幅。
- **频谱图**：将 PCM 通过 **FFT（快速傅里叶变换）** 转换得到的三维数据结构（X轴=时间，Y轴=频率，Z轴=振幅/响度）。
- **偏移量**：当录音中的某个指纹哈希值匹配到原曲时，`偏移量 = T_原曲出现秒数 - T_录音出现秒数`。正确匹配的歌曲，所有哈希值的偏移量必然恒定。

---

## 二、Shazam 算法核心流程（优化版）

1. **音频解码与预处理**：将 MP3/WAV/FLAC 等压缩格式统一解码为 **16bit、单声道、8000Hz 采样率** 的 PCM 裸数据（降采样可减少后续 FFT 的计算量）。
2. **生成频谱图（FFT）**：对 PCM 进行分帧（通常每帧约 16ms），对每一帧执行 FFT，得到时间-频率-振幅的三维频谱图。
3. **提取局部极大值（找"山峰"）**：
   - 将频谱图划分为微小的重叠网格（时间约 16ms，频率约 20Hz）。
   - **[优化]** 执行**二维峰值检测**：某个点必须在**频率轴**（比上下频率点响）和**时间轴**（比前后时间帧响）上均高于邻居，才被选为候选点。
   - 过滤掉低于绝对能量阈值的点（消除背景底噪）。每帧只保留能量最强的 Top-N（如 5 个）点，最终形成"星云图"。
4. **生成哈希指纹（配对）**：
   - 选定一个锚点（Anchor），在其后一段极短的时间窗内（如 200ms）寻找其他目标点（Target）。
   - **[优化]** **同时限定距离**：不仅限制时间差，也限制目标点与锚点之间的频率差值（以防止低频噪音干扰或极不稳定的远距离配对）。
   - 将配对信息 `(锚点频率, 目标点频率, 时间差)` 通过哈希函数压缩成一个 **32位或64位** 的整数 Key。
5. **存储倒排索引**：将哈希 Key 作为索引，存入数据库，同时记录该哈希对应的 `(歌曲ID, 该点在原曲中的绝对时间T_原曲)`。
6. **匹配与投票（直方图统计）**：
   - 用录音提取的哈希 Key 查询数据库，得到所有候选歌曲的匹配记录。
   - 计算每条记录的 `偏移量 = T_原曲 - T_录音`。
   - 建立直方图，统计每个偏移量出现的次数。**得票最高的偏移量对应的歌曲**，即为最终识别结果。

---

### 3.2 音频解码与预处理（含关键低通滤波）

**[优化]** 此处修正了常见的工程陷阱：**降采样前必须进行低通滤波，以防止高频信号混叠（Aliasing）破坏频谱图**。

```java
public class AudioProcessor {
    
    public static double[] decodeToPCM(File audioFile, int targetSampleRate) throws Exception {
        // 1. 读取原始音频流
        AudioInputStream rawStream = AudioSystem.getAudioInputStream(audioFile);
        AudioFormat rawFormat = rawStream.getFormat();

        // 2. 转换为 PCM 16bit
        AudioFormat pcmFormat = new AudioFormat(
            AudioFormat.Encoding.PCM_SIGNED,
            rawFormat.getSampleRate(),
            16,
            rawFormat.getChannels(),
            rawFormat.getChannels() * 2,
            rawFormat.getSampleRate(),
            false // 小端序
        );
        AudioInputStream pcmStream = AudioSystem.getAudioInputStream(pcmFormat, rawStream);

        // 3. 读取全部采样点并转为 short[]
        byte[] pcmBytes = readAllBytes(pcmStream);
        int channels = pcmFormat.getChannels();
        int sampleRate = (int) pcmFormat.getSampleRate();
        short[] shorts = bytesToShorts(pcmBytes, channels);

        // 4. 立体声合并为单声道
        double[] mono = toMono(shorts, channels);

        // 5. [优化] 必须首先进行低通滤波（截止频率为 targetSampleRate/2）
        //    否则降采样会产生镜像频率干扰（混叠效应）
        double[] filtered = lowPassFilter(mono, sampleRate, targetSampleRate / 2.0);

        // 6. 降采样到目标采样率（如 8000Hz）
        double[] resampled = resample(filtered, sampleRate, targetSampleRate);

        // 7. 归一化到 [-1.0, 1.0]
        normalize(resampled);
        return resampled;
    }

    /**
     * [优化] 基于 JTransforms 的频域低通滤波
     * 核心思路：将信号通过 FFT 转换到频域 → 将截止频率以上的分量全部置零 → IFFT 回到时域
     * 这种方式比时域 FIR 卷积更高效，且截止特性更陡峭
     * 截止频率设为 targetSampleRate/2，满足奈奎斯特采样定理，防止降采样混叠
     */
    private static double[] lowPassFilter(double[] input, int origRate, double cutoffFreq) {
        DoubleFFT_1D fft = new DoubleFFT_1D(input.length);
        
        // JTransforms 的 realForwardFull 需要长度为 2*N 的数组来存放复数结果
        // 偶数索引存实部，奇数索引存虚部
        double[] data = new double[input.length * 2];
        for (int i = 0; i < input.length; i++) {
            data[i] = input[i];
        }
        
        // 正向 FFT：将时域信号转换到频域
        fft.realForwardFull(data);
        
        // 计算截止频率对应的频域 bin 索引
        // 频率分辨率 = origRate / input.length，cutoffBin = cutoffFreq / 频率分辨率
        int cutoffBin = (int) (cutoffFreq * input.length / origRate);
        
        // 将截止频率以上的频域分量置零（理想的低通矩形窗）
        // 注意：data 数组布局为 [re0, re1, im1, re2, im2, ... reN-1, imN-1, reN]
        // 从 cutoffBin*2 开始到末尾全部置零（即实部和虚部都清零）
        for (int i = cutoffBin * 2; i < data.length; i++) {
            data[i] = 0.0;
        }
        
        // 逆向 FFT：将滤波后的频域信号还原为时域信号
        fft.complexInverse(data, true); // true 表示执行缩放（除以 N）
        
        // 提取实部作为滤波结果
        double[] result = new double[input.length];
        for (int i = 0; i < input.length; i++) {
            result[i] = data[i * 2]; // 偶数索引对应实部
        }
        return result;
    }

    private static byte[] readAllBytes(AudioInputStream stream) throws IOException {
        ByteArrayOutputStream buffer = new ByteArrayOutputStream();
        byte[] buf = new byte[8192];
        int n;
        while ((n = stream.read(buf)) != -1) {
            buffer.write(buf, 0, n);
        }
        return buffer.toByteArray();
    }

    private static short[] bytesToShorts(byte[] bytes, int channels) {
        int totalFrames = bytes.length / (channels * 2);
        short[] shorts = new short[totalFrames * channels];
        ByteBuffer.wrap(bytes).order(ByteOrder.LITTLE_ENDIAN).asShortBuffer().get(shorts);
        return shorts;
    }

    private static double[] toMono(short[] shorts, int channels) {
        int totalFrames = shorts.length / channels;
        double[] mono = new double[totalFrames];
        for (int i = 0; i < totalFrames; i++) {
            if (channels == 2) {
                mono[i] = (shorts[i * 2] + shorts[i * 2 + 1]) / 2.0;
            } else {
                mono[i] = shorts[i];
            }
        }
        return mono;
    }

    private static double[] resample(double[] input, int origRate, int targetRate) {
        // 降采样实现：可简单抽值或使用线性插值
        if (origRate == targetRate) return input;
        double ratio = (double) targetRate / origRate;
        int newLen = (int) (input.length * ratio);
        double[] output = new double[newLen];
        for (int i = 0; i < newLen; i++) {
            double srcPos = i / ratio;
            int idx = (int) srcPos;
            double frac = srcPos - idx;
            if (idx + 1 < input.length) {
                output[i] = input[idx] * (1 - frac) + input[idx + 1] * frac;
            } else {
                output[i] = input[idx];
            }
        }
        return output;
    }

    private static void normalize(double[] data) {
        double max = 0.0;
        for (double v : data) {
            max = Math.max(max, Math.abs(v));
        }
        if (max > 0) {
            for (int i = 0; i < data.length; i++) {
                data[i] /= max;
            }
        }
    }
}
```



### 3.3 频谱图生成与峰值提取（二维局部极大值）

**[优化]** 代码中显式加入了**时间轴上的比较**，真正实现了"矩形区域内的山峰查找"。

```java
public class FingerprintExtractor {
    
    private static final int FFT_SIZE = 1024;       // 约 128ms @ 8000Hz
    private static final int HOP_SIZE = 512;        // 帧移，重叠 50%
    private static final float ENERGY_THRESHOLD = 10.0f;
    private static final int TOP_PEAKS_PER_FRAME = 5;

    /**
     * 计算声谱图：对 PCM 分帧，每帧做 FFT
     * @return spectrogram[时间帧索引][频率索引]
     */
    public float[][] computeSpectrogram(double[] pcmData) {
        int numFrames = (pcmData.length - FFT_SIZE) / HOP_SIZE + 1;
        float[][] spectrogram = new float[numFrames][FFT_SIZE / 2 + 1];
        
        DoubleFFT_1D fft = new DoubleFFT_1D(FFT_SIZE);
        double[] window = createHanningWindow(FFT_SIZE);
        double[] frame = new double[FFT_SIZE];
        
        for (int t = 0; t < numFrames; t++) {
            int start = t * HOP_SIZE;
            System.arraycopy(pcmData, start, frame, 0, FFT_SIZE);
            
            // 加窗（减少频谱泄露）
            for (int i = 0; i < FFT_SIZE; i++) {
                frame[i] *= window[i];
            }
            
            // FFT
            fft.realForward(frame);
            
            // 计算幅度谱（仅保留正频率部分）
            for (int f = 0; f <= FFT_SIZE / 2; f++) {
                double re = frame[2 * f];
                double im = (f == 0 || f == FFT_SIZE / 2) ? 0 : frame[2 * f + 1];
                spectrogram[t][f] = (float) Math.sqrt(re * re + im * im);
            }
        }
        return spectrogram;
    }

    private double[] createHanningWindow(int size) {
        double[] window = new double[size];
        for (int i = 0; i < size; i++) {
            window[i] = 0.5 * (1 - Math.cos(2 * Math.PI * i / (size - 1)));
        }
        return window;
    }

    /**
     * [优化] 二维局部极大值检测：同时检查时间轴和频率轴
     */
    public List<Peak> findPeaks(float[][] spectrogram) {
        List<Peak> peaks = new ArrayList<>();

        for (int t = 1; t < spectrogram.length - 1; t++) {
            for (int f = 1; f < spectrogram[t].length - 1; f++) {
                float current = spectrogram[t][f];
                
                // 检查频率轴左右邻居
                boolean isFreqPeak = current > spectrogram[t][f-1] && current > spectrogram[t][f+1];
                // 检查时间轴前后邻居
                boolean isTimePeak = current > spectrogram[t-1][f] && current > spectrogram[t+1][f];
                // 检查绝对能量阈值
                boolean isLoudEnough = current > ENERGY_THRESHOLD;

                if (isFreqPeak && isTimePeak && isLoudEnough) {
                    peaks.add(new Peak(t, f, current));
                }
            }
        }

        // 每帧只保留能量最强的 Top 5（减少数据量，提升抗噪性）
        return keepTopKPerFrame(peaks, TOP_PEAKS_PER_FRAME);
    }

    private List<Peak> keepTopKPerFrame(List<Peak> peaks, int k) {
        Map<Integer, List<Peak>> frameMap = new HashMap<>();
        for (Peak p : peaks) {
            frameMap.computeIfAbsent(p.frame, key -> new ArrayList<>()).add(p);
        }
        
        List<Peak> result = new ArrayList<>();
        for (List<Peak> framePeaks : frameMap.values()) {
            framePeaks.sort((a, b) -> Float.compare(b.amplitude, a.amplitude));
            result.addAll(framePeaks.subList(0, Math.min(k, framePeaks.size())));
        }
        return result;
    }

    static class Peak {
        int frame;
        int freq;
        float amplitude;
        
        Peak(int frame, int freq, float amplitude) {
            this.frame = frame;
            this.freq = freq;
            this.amplitude = amplitude;
        }
    }
}
```



### 3.4 哈希配对生成（带频率范围限制）

**[优化]** 配对时同时约束**时间距离**和**频率距离**，生成的指纹更加鲁棒。

```java
public class FingerprintMatcher {
    
    private static final int MIN_DELTA_FRAME = 3;      // 最小时间差（帧数）
    private static final int MAX_DELTA_FRAME = 10;     // 最大时间差（帧数）
    private static final int MAX_FREQ_DELTA = 2000;    // [优化] 最大允许频率差（Hz）

    /**
     * 从峰值列表中生成哈希指纹
     */
    public List<HashRecord> extractFingerprints(List<Peak> peaks, int songId, int sampleRate) {
        List<HashRecord> records = new ArrayList<>();

        for (int i = 0; i < peaks.size(); i++) {
            Peak anchor = peaks.get(i);
            
            for (int j = i + 1; j < peaks.size(); j++) {
                Peak target = peaks.get(j);
                int deltaFrame = target.frame - anchor.frame;
                
                // 限制时间窗口：太近的不要（易受瞬时噪声干扰），太远的也不要（增加计算量）
                if (deltaFrame < MIN_DELTA_FRAME || deltaFrame > MAX_DELTA_FRAME) {
                    continue;
                }
                
                // [优化] 限制频率差值：只匹配频率相近的谱峰
                int deltaFreq = Math.abs(target.freq - anchor.freq);
                if (deltaFreq > MAX_FREQ_DELTA) {
                    continue;
                }

                // 构造哈希 Key：使用位运算压缩成 long
                // 频率值实际是 FFT bin 索引，需换算为实际频率
                int anchorFreqHz = anchor.freq * sampleRate / (FingerprintExtractor.FFT_SIZE);
                int targetFreqHz = target.freq * sampleRate / (FingerprintExtractor.FFT_SIZE);
                
                long hashKey = ((long) anchorFreqHz << 32) 
                             | ((long) targetFreqHz << 16) 
                             | deltaFrame;

                // 存储：哈希Key，歌曲ID，锚点在该歌曲中的绝对时间（秒）
                double anchorTime = (double) anchor.frame * FingerprintExtractor.HOP_SIZE / sampleRate;
                records.add(new HashRecord(hashKey, songId, anchorTime));
            }
        }
        return records;
    }

    static class HashRecord {
        long hashKey;
        int songId;
        double anchorTime;
        
        HashRecord(long hashKey, int songId, double anchorTime) {
            this.hashKey = hashKey;
            this.songId = songId;
            this.anchorTime = anchorTime;
        }
    }
}
```



### 3.5 匹配与投票（直方图统计）

```java
public class SongMatcher {
    
    /**
     * 匹配录音提取的哈希列表，返回命中的歌曲ID
     */
    public int matchSong(List<HashRecord> queryHashes, HashDatabase database) {
        // 存储候选歌曲的偏移量投票
        Map<Integer, Map<Double, Integer>> votes = new HashMap<>();

        for (HashRecord query : queryHashes) {
            // 查询数据库：该哈希值在哪些歌曲的哪些位置出现过
            List<HashRecord> candidates = database.lookup(query.hashKey);
            
            for (HashRecord candidate : candidates) {
                // 计算偏移量：原曲时间 - 录音时间
                double offset = candidate.anchorTime - query.anchorTime;
                
                // 投票：偏移量取整到 0.1 秒精度（抵御微小时钟漂移）
                double roundedOffset = Math.round(offset * 10.0) / 10.0;
                
                Map<Double, Integer> songVotes = votes.computeIfAbsent(
                    candidate.songId, k -> new HashMap<>()
                );
                songVotes.put(roundedOffset, songVotes.getOrDefault(roundedOffset, 0) + 1);
            }
        }

        // 找出投票数最高的歌曲及偏移量
        int bestSongId = -1;
        int bestVoteCount = 0;
        
        for (Map.Entry<Integer, Map<Double, Integer>> songEntry : votes.entrySet()) {
            int songId = songEntry.getKey();
            int maxVote = songEntry.getValue().values().stream()
                                  .max(Integer::compareTo)
                                  .orElse(0);
            
            if (maxVote > bestVoteCount) {
                bestVoteCount = maxVote;
                bestSongId = songId;
            }
        }

        // 工程阈值：票数低于 3 视为未识别
        return bestVoteCount >= 3 ? bestSongId : -1;
    }
}
```

## 四、性能与优化策略总结

| 优化点                | 说明                                                         |
| :-------------------- | :----------------------------------------------------------- |
| **降采样与低通滤波**  | 将采样率降至 8000Hz（计算量减少至原来的 1/30），**务必先滤波后降采样**，防止混叠干扰。 |
| **峰值稀疏化**        | 单帧只保留 Top-5 峰值，大幅减少后续配对和数据库存储的压力。  |
| **哈希索引**          | 不存储原始音频，只存储整数哈希 Key。数据库层利用倒排索引，实现百万级曲库的毫秒级查询。 |
| **重叠帧（Overlap）** | FFT 分帧时采用 50% 重叠（如 FFT_SIZE=1024, HOP_SIZE=512），确保旋律变化平滑，不漏特征。 |
| **投票阈值**          | 实际工程中，如果最高票数低于绝对数量（如小于 3 票），直接返回"未识别"，避免误报。 |
| **二维峰值检测**      | 同时检查时间轴和频率轴，确保选出的"山峰"在二维平面上都是局部最高点。 |
| **配对频率限制**      | 限制锚点和目标点的频率差值，防止跨频带过于悬殊的配对产生不稳定的哈希。 |
