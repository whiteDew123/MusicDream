## 🎮 交互体验协议 · 音乐项目专属（v1.0 — 暗色版）

### 适用范围说明

| 设计源 | 适用的交互协议章节 |
| :--- | :--- |
| `design-spotify.md`（播放端·暗色） | **第一、二、三章**（播放器 + 内容浏览 + 反馈） |
| 管理端 | 暂不支持暗色，保持亮色 Webflow 交互（见 `../frontend-design-standards/animation.md` 第四章） |

### 第一章 · 播放端：播放器核心交互（Spotify 暗色适配）

> 以下交互仅应用于播放器界面、歌单详情页、当前播放栏。

| 交互场景 | 行为描述 | 参数规格 |
| :--- | :--- | :--- |
| **播放/暂停按钮** | 点击时图标切换伴随弹性缩放动画，模拟"启动音乐"的物理感。暗色下按钮为 Spotify Green 圆形，按压缩放更明显 | `transform: scale(0.85) → 1.15 → 1`，时长 350ms，缓动 `ease-out`；按钮背景 `#1ed760`，图标 `#000000` |
| **进度条拖拽** | 拖拽时滑块圆点放大 1.3 倍，松手后回弹；拖拽过程中显示实时时间戳浮标 | 圆点放大过渡 150ms；时间戳浮标跟随鼠标位置，带 100ms 延迟跟随；已播放部分填充 Spotify Green `#1ed760` |
| **音量滑块** | 悬停时滑块轨道高亮（Spotify Green `#1ed760`），拖拽时圆点放大 1.2 倍 | 轨道高亮过渡 200ms；圆点缩放 150ms |
| **歌曲切换（上一首/下一首）** | 点击时当前歌曲信息做"滑出"过渡，新歌曲"滑入" | 滑出 200ms `ease-in`，滑入 250ms `ease-out`，间隔 50ms |
| **歌词滚动（如有）** | 歌词随播放进度自动滚动，当前行高亮并居中 | 自动滚动使用 `scrollIntoView` 配合 `smooth`，高亮行使用 Spotify Green `#1ed760`；非当前行 `#b3b3b3` |


### 第二章 · 播放端：内容浏览交互（Spotify 暗色适配）

> 以下交互应用于首页、歌单列表、歌手页、搜索结果等浏览场景。

| 交互场景 | 行为描述 | 参数规格 |
| :--- | :--- | :--- |
| **歌单/专辑卡片悬停** | 卡片略微上浮，背景从 `#181818` 变亮至 `#1f1f1f`，同时显示一个圆形播放按钮（Spotify Green `#1ed760`）从底部渐显上浮 | 上浮 `translateY(-6px)`，背景过渡 250ms；播放按钮从 `translateY(8px)` 上浮到 `translateY(0)`，透明度 0 → 1，300ms `ease-out`；卡片阴影 `rgba(0,0,0,0.5) 0px 8px 24px` |
| **列表项悬停** | 歌曲列表项背景变亮（从 `#121212` → `#1f1f1f`），同时右侧出现"···"更多菜单按钮 | 背景过渡 150ms；更多按钮渐显 200ms |
| **列表项点击** | 点击后高亮保持（表示"当前选中/正在播放"），左侧出现 Spotify Green（`#1ed760`）竖条指示器，当前行文字变白 `#ffffff` | 竖条宽度 4px，出现动画 200ms `ease-out` |
| **列表加载（分页/滚动加载）** | 新条目从下往上滑入，每条间隔 50ms，形成交错入场效果 | `translateY(12px) → 0`，透明度 0 → 1，每条 300ms，间隔 50ms |
| **搜索输入** | 输入时自动展开搜索建议下拉，建议项悬停时背景变亮（`#121212` → `#1f1f1f`） | 下拉展开 300ms `ease-out`；建议项悬停 150ms |
| **下拉刷新（移动端）** | 下拉时顶部出现加载指示器（Spotify Green `#1ed760` 旋转圆环），松手后刷新 | 圆环旋转动画 800ms 循环；刷新完成后 300ms 淡出 |


### 第三章 · 播放端：反馈与过渡（Spotify 暗色适配）

> 以下交互应用于全局反馈、页面流转、等待状态。

| 交互场景 | 行为描述 | 参数规格 |
| :--- | :--- | :--- |
| **页面切换** | 路由跳转时使用平滑淡入淡出，避免生硬闪屏 | `opacity: 0 → 1`，时长 250ms `ease-out` |
| **收藏/点赞操作** | 点击心形图标时，图标做"弹跳"动画，从空心变为实心 Spotify Green `#1ed760` | 弹跳：`scale(0.6 → 1.3 → 1)`，时长 400ms；颜色过渡 300ms |
| **Toast 提示** | 操作成功/失败时，从页面底部滑入轻提示，暗色背景 `#282828` + 白色文字，附带进度条自动消失 | 滑入 350ms `ease-out`，停留 3 秒，滑出 300ms `ease-in`；进度条从左到右填充 3 秒 |
| **骨架屏（加载中）** | 所有列表/卡片加载时优先显示骨架屏，暗色骨架颜色 `#1f1f1f`（介于 `#121212` 和 `#282828` 之间） | 骨架脉冲动画：透明度 0.4 ↔ 0.8，循环 1.2 秒 |
| **操作确认（删除/清空）** | 危险操作触发二次确认对话框，对话框背景 `#282828`，遮罩 `rgba(0,0,0,0.7)` | 对话框出现 300ms `scale(0.95 → 1)` + 背景遮罩 200ms 淡入 |

> 管理端暂不支持暗色模式，保持亮色 Webflow 交互。暗色适配将在后续版本中补充。


### 第五章 · 全局基础交互（两端共用）

> 以下交互同时应用于应用端和管理端，保证基础体验的一致性。

| 交互场景 | 行为描述 | 参数规格 |
| :--- | :--- | :--- |
| **滚动条** | 全局自定义滚动条：细条 + 圆角，轨道透明，暗色下滑块使用 `#4d4d4d`（半透明灰），悬停时 `#757575` | 宽度 6px，圆角 3px；滑块颜色过渡 150ms |
| **链接悬停** | 所有文字链接悬停时变为 Spotify Green `#1ed760` | 颜色过渡 150ms |
| **加载 Spinner** | 仅在骨架屏不可用的极少数场景使用（如按钮内加载），使用 Spotify Green `#1ed760` 圆环 | 旋转动画 1s 线性循环 |
| **焦点指示** | 所有可交互元素（按钮、输入框、链接）获得键盘焦点时，显示 Spotify Green `#1ed760` 聚焦环 | 2px 聚焦环，偏移 2px |

### 📊 暗色 vs 亮色交互关键差异

| 交互项 | 亮色版（Stripe） | 暗色版（Spotify） |
| :--- | :--- | :--- |
| **卡片悬停** | 背景变暗（`#ffffff` → `#f0f4f8`） | 背景变亮（`#181818` → `#1f1f1f`） |
| **卡片悬停阴影** | `0 4px 20px rgba(0,0,0,0.08)` | `rgba(0,0,0,0.5) 0px 8px 24px` |
| **列表项悬停** | 背景变暗（`#ffffff` → `#f0f4f8`） | 背景变亮（`#121212` → `#1f1f1f`） |
| **强调色** | Stripe 紫（`#5e5ce6`） | Spotify Green（`#1ed760`） |
| **骨架屏颜色** | `#e8ecf0` | `#1f1f1f` |
| **阴影原则** | 轻阴影即见层次 | 重阴影才可见，暗色下需 0.3–0.5 透明度 |
| **Toast 背景** | 白色卡片 + 浅阴影 | 暗色卡片 `#282828` + 重阴影 |
| **播放按钮** | 紫色圆形 | Spotify Green 圆形（`#1ed760` 背景 + `#000000` 图标） |
| **按钮形状** | 圆角矩形（`rounded.sm` 4px） | 全圆角胶囊（500px–9999px） |


### 💡 特别说明

- **交互动作本身不变**（弹性缩放、入场动画、Toast 滑入等），变的只是**颜色值、背景色方向（变亮→变暗方向反转）、阴影参数**
- 暗色下阴影必须比亮色**重得多**（0.3–0.5 透明度 + 更大 blur），否则在深色背景上完全不可见
- 暗色播放端强调 **"UI 退居幕后"**，Spotify Green 只用做功能性高亮（播放/激活/CTA），不做装饰
- 卡片悬停时背景**变亮**而非变暗，这是暗色与亮色最核心的交互方向差异
- 管理端暗色暂未实现，本章第四章引用亮色版交互协议
